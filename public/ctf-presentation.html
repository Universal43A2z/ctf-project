BUILT WITH
Technology Stack

▸ Backend — Node.js + Express 5 — lightweight server-side runtime and HTTP framework.

▸ Templating — EJS — server-side render; flags never reach the browser.

▸ Auth & session — express-session (httpOnly cookie) + bcrypt password hashing.

▸ Security middleware — helmet (CSP + headers), express-rate-limit, express-validator, CSRF tokens, constant-time flag comparison.

▸ Data layer — JSON file stores (data.json users · ctf-challenges.js catalog) — zero external DB.

▸ Frontend & deploy — Vanilla CSS (CSS variables, dual themes) + ES5 JS (theme.js) + Cloudflare tunnel for the live link.

EAT YOUR OWN DOG FOOD
Security & Best Practices

▸ Headers — helmet defaults + strict CSP: inline scripts blocked — theme.js must use addEventListener.

▸ Input & auth — express-validator, bcrypt hashes, httpOnly session cookie, rate limiters on login/auth/admin.

▸ CSRF — every state-changing form (login, register, logout, flags, admin) carries a per-session token.

▸ Timing-safe & scoped — constant-time flag comparison prevents length/content oracle leaks; flags never rendered client-side.

▸ Least privilege — requireAuth guards protected pages; single admin key override via env (ADMIN_KEY).
